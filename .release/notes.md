Проверка edit-check сохраняет контекст родительских Python-пакетов, чтобы Ruff одинаково классифицировал импорты в изолированном дереве и в проекте.

Публикация и обновление потребителей корректно сравнивают ревизии GitHub по полным SHA.

Полная проверка сообщает о крупных этапах и допускает четыре одновременных локальных запуска. Вложенный запуск старой двухслотовой версии из нового слота может завершиться как unchecked; обновите вложенную версию Quality Gate.
