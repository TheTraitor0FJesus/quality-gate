Проверка edit-check сохраняет контекст родительских Python-пакетов, чтобы Ruff одинаково классифицировал импорты в изолированном дереве и в проекте.

Публикация и обновление потребителей корректно сравнивают ревизии GitHub по полным SHA.

Если файл появляется внутри принадлежащего Quality Gate каталога после первичного обхода, очистка повторно сканирует каталог и удаляет новую запись с проверкой идентичности. Число повторных обходов ограничено. Если содержимое продолжает меняться, очистка завершится видимой ошибкой.

Ключ и запись очистки публикуются после полной записи, а оборванная запись не мешает восстановить рабочий каталог при подтверждённом владении. На POSIX для журналов сохраняется отдельная защищённая область для каждого ключа; прежние и чужие области не удаляются при смене пользовательского состояния.

Постоянные нативные кэши Ruff и mypy можно повторно использовать между снимками, если совпадают исходный репозиторий, версия движка, закреплённые инструменты, политика, runtime и параметры запуска. Каждая проверка по-прежнему запускает инструмент; при занятом или небезопасном общем кэше используется private cache и проверка продолжается.
Полная проверка сообщает о крупных этапах и допускает четыре одновременных локальных запуска. Вложенный запуск старой двухслотовой версии из нового слота может завершиться как unchecked; обновите вложенную версию Quality Gate.
