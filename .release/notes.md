# Quality Gate 4.4.0

Рабочая типизация поддерживает локальные `stub_roots` внутри Python-компонента.
Провайдер включает `.pyi` в инвентарь и передаёт проверенные каталоги isolated mypy.

Все команды проверки изменений используют общий временный workspace под `temp/qg-*`.
Активные запуски защищены блокировками, а для read-only корней используется системный
временный каталог.

Чтобы использовать `stub_roots`, потребителям потребуется установить
`quality.policy_release = "v4.4.0"` и закрепить совместимый reusable workflow SHA.
Для остальных потребителей изменения `quality-gate.toml` не требуются.
