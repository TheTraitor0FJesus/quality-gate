# Quality Gate v4.9.0

Добавлена совместимая политика для защищённого auto-merge minor/patch обновлений Dependabot, включая исправления безопасности. Контроллер проверяет каждую зависимость, текущий head и обязательную защиту ветки. Major и неизвестные обновления требуют решения владельца. Обычные обновления сгруппированы по экосистеме и проверяются ежемесячно.

Release CI сохраняет полный набор тестов внутри проверки собранного артефакта. Повторный внешний pytest заменён проверкой готовности закреплённой политики через `doctor`; Linux, Windows и проверка точного исходного коммита сохранены. В логах появились длительности этапов, включая финализацию и очистку. Причина исторической задержки после тестов ещё не подтверждена.

Команда `runtimes --json` сохраняет структурированный JSON при ошибках инвентаризации. В разработческих зависимостях обновлён Ruff. Из репозитория удалена конфигурация CodeRabbit.

Для включения нового Dependabot-контроллера после публикации требуется отдельная проверяемая активация provider policy и workflow по `docs/quality-policy-changes.md`. Прежний workflow поддерживается. Пины остальных потребителей обновляются явно через обычный rollout.
