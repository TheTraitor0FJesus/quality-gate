# Quality Gate 3.2.0

Добавлена `quality-gate edit-integrity` для read-only проверки явного ограниченного списка полных рабочих файлов. Маркеры конфликтов и точные standard waivers совпадают с обычным Gate. Проверка подтверждает SHA-256 исходных байтов, manifest и immutable policy перед ответом. NUL и невалидный UTF-8 сохраняют семантику Gate для бинарных файлов. Неполное чтение, устаревшие данные, неподдерживаемый pin, превышение лимитов и дедлайн возвращают `unchecked`.

Это MINOR относительно опубликованной v3.1.0. Engine сохраняет поддерживаемые policy pins и добавляет v3.2.0 после публикации. Релиз не устанавливает и не включает host hook и не обновляет consumer pins. Для активации нужны установка опубликованного provider и отдельная host-приёмка по `docs/edit-integrity.md`.
