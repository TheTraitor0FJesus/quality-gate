# Quality Gate 4.2.0

Полный локальный Gate допускает два одновременных запуска для текущего пользователя между проектами. Если оба слота заняты, следующий запуск ждёт до 120 секунд и продолжает проверку после освобождения слота. По истечении бюджета Gate сообщает `unchecked` и не начинает проверку. Лимит ожидания задаёт `QUALITY_GATE_QUEUE_TIMEOUT_SECONDS`.

Полные проверки Ruff по умолчанию используют четыре потока. Лимит можно изменить через `QUALITY_GATE_RUFF_THREADS`.

Для включения поведения выберите policy `v4.2.0`. CI не использует локальную очередь. Перед активацией новой policy в native commit hook обновите внешний timeout bridge, чтобы он покрывал время ожидания и полный Gate.

В репозитории Quality Gate лимит полного pytest увеличен до 30 минут, всего Gate — до 40 минут, а общего CI workflow — до 50 минут с учётом подготовки и очистки.
